Verify the deployment
---------------------
  kubectl -n {{ .Release.Namespace }} get pods,svc,pdb
  kubectl -n {{ .Release.Namespace }} rollout status deploy/{{ include "durable-workflow.serverDeploymentName" . }}
  kubectl -n {{ .Release.Namespace }} rollout status deploy/{{ include "durable-workflow.workerDeploymentName" . }}

Probe the readiness contract (must return 200 once migrations finish):

  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "durable-workflow.serverDeploymentName" . }} 8080:{{ .Values.server.service.port }}
  curl http://localhost:8080/api/health
  curl http://localhost:8080/api/ready
