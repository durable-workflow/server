- **What changed on 2.11.8, and the answers recorded.**
  - **Post-commit payload deletion counts** (#911). Every retention pass
    and namespace delete answer carries `external_payload_cleanup`, and the
    payload cleanup status and pass carry `retention_cleanup`
    (`pending`, `failed`, `blocked`). Native added them only while a
    deletion was pending (#914); it now always does. `namespace-delete`,
    `payload-cleanup`, `retention-external-payloads` and
    `namespace-delete-payloads` pin the counts.
  - **A child resolved under a leased parent task** (workflow#962, Core
    2.15.10). `child-open-parent-task` gains a leased case: the parent's
    resume task is claimed, the child completes, and the lease completes
    with a timer and without the result. 2.11.8 then offers one follow-up
    task that replays the child's result, as native does. Native left that
    moment's run summary unprojected (a resolved child beside the timer);
    it now describes it as 2.11.8 does: `timer_scheduled`, waiting for the
    timer, no repair attention.
  - **History import** (Core 2.15.8 to 2.15.12). The `workflow-import`
    probe's run id conflict bundle renamed only `workflow.run_id`; 2.11.8
    checks each command's and signal's `resolved_run_id` first, so the
    probe now renames every `*run_id` naming the original run, and the case
    still answers `target.run_id_conflict`. The cross-namespace attach now
    answers `target.instance_namespace_conflict` before writing, and a run
    imported into another namespace answers as a conflict; native matches
    both, and the fixture's published-defect allowances for 2.11.1 to
    2.11.7 are removed.
  - **Embedded probes.** Core 2.15.12 resolves a run through its
    instance's namespace and reserves a caller-named instance without
    model events, so the probes' `creating` hooks left that instance's
    namespace empty and every embedded recording failed to find its run.
    The embedded probes now configure `workflows.v2.namespace`. A host
    application without the hooks is unaffected.
