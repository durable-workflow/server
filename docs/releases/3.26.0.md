# Durable Workflow Server 3.26.0 (native)

Server can recover a lost parent resume task while a selection awaits a child
workflow or a nested child-only `all()` group. It records the original wait in
the parent's history and repairs from the completing child, or from the first
failure while another child is still running. On replay, the worker receives
the result of the same authored wait.

A condition in the same selection can reopen when the predicate is still
false. Server keeps its original selection identity and, for timed conditions,
its original deadline.

Install PHP SDK 3.28.0 alongside this Server version for the new worker
capability.

## Upgrade from 3.25.0

The database schema is unchanged. For Docker Compose, replace the published
Compose file and start the stack with the new image. Server verifies the
existing schema at startup. For an earlier schema, follow the
[stopped-node upgrade](3.22.0.md#upgrade-from-3210).
