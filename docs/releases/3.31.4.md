# Durable Workflow Server 3.31.4 (native)

This patch keeps the 3.30.0 database schema on every backend. Deployments on
3.30.0 through 3.31.3 can upgrade without a schema migration.

A continued workflow can receive a signal declared by its own worker while
waiting on a timer. Signals accepted before the successor completes its first
task become eligible once that task binds the successor's command declaration.
The declaration follows the chosen successor workflow type and queue.
[Server #1402](https://github.com/durable-workflow/server/issues/1402)
