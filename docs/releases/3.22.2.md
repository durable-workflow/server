# Durable Workflow Server 3.22.2 (native)

The native Server updates its Rust URL dependency to `url` 2.5.9. Published
native images built from this release include the dependency fix.

## Upgrade from 3.22.1

The database schema and worker protocol are unchanged. For Docker Compose,
replace the published Compose file and start the stack with the new image.
Server verifies the existing schema during startup. An earlier schema still
requires the [stopped-node upgrade](3.22.0.md#upgrade-from-3210).
