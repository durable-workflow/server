# Durable Workflow Server 3.24.0 (native)

Conditions can be members of an `all` group. The barrier releases when every
member has resolved. A signal wakes the open conditions in the group. If a
condition is still false, Server records a new physical wait at the same
authored group position. A replacement uses the authored per-open timeout.

Server returns `grouped_condition_waits` version 1 at worker registration
when the worker declares `grouped_condition_wait_replay`. PHP SDK 3.26.0
supports replay of these waits after a worker restart.

## Upgrade from 3.23.0

The database schema and worker protocol version are unchanged. For Docker
Compose, replace the published Compose file and start the stack with the new
image. Server verifies the existing schema during startup. An earlier schema
still requires the [stopped-node upgrade](3.22.0.md#upgrade-from-3210).

Upgrade every worker eligible to run these workflows before authoring grouped
conditions. Keep replay-capable workers available while those histories can
still be assigned.
