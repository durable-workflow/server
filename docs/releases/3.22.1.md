# Durable Workflow Server 3.22.1 (native)

The published Compose file now prepares the MySQL schema before starting
Server. When binary logging requires an administrator to install the
checkpoint code, the one-shot installer applies the plan generated by the
scoped Server account. Server verifies the result and starts with its
regular database credentials. Both phases use the existing MySQL instance
and keep its binary logging settings.

## Upgrade from 3.22.0

The database schema and worker protocol stay at the 3.22.0 versions. Replace
the published Compose file and start the stack with the new image. A database
already on the 3.22.0 schema is verified before Server starts. An earlier
schema still requires the [stopped-node upgrade](3.22.0.md#upgrade-from-3210).
