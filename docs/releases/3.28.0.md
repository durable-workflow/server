# Durable Workflow Server 3.28.0 (native)

Workers can receive tasks through signed offers. Without offers, a lost poll
response can strand a lease until it expires. With offers, Server first offers
a ready task without leasing it, and leases it only when the same worker accepts
that offer. If the acceptance response is lost, the worker repeats the exact
acceptance and receives the same lease instead of waiting for it to expire.
Offers are bound to the worker registration, namespace, queue, task and
attempt, and expire after a short window.

Offers are off unless `DW_TASK_DELIVERY_SEAL_KEYS` is set. The value is a JSON
object with `schema` `durable-workflow.task-delivery-seal-keys.v1` and one to
four `keys`, each with an `id` and a 32-byte `key_base64`. The first key issues
offers and every listed key can read them. An empty or malformed value refuses
configuration. Keep a retiring key listed until no live or replayable claim
uses it. If a required key is missing at startup, Server still starts and serves
ordinary polling, stops advertising offers, and answers a packet that needs the
missing key with a retryable `task_offer_read_key_unavailable`.

A worker that declares `task_delivery_offers` at registration and receives the
descriptor uses offers for the polls that select a task. A task carried by a
completion response still arrives on the legacy route and recovers through the
existing carried-poll replay. Other workers keep the existing poll endpoints. PHP
SDK 3.30.0 is the first SDK that uses offers.

## Upgrade from 3.27.0

The database schema and worker protocol version are unchanged. For Docker
Compose, replace the published Compose file and start the stack with the new
image. Server verifies the existing schema at startup. For an earlier schema,
follow the [stopped-node upgrade](3.22.0.md#upgrade-from-3210).

To enable offers, set `DW_TASK_DELIVERY_SEAL_KEYS` on every Server process that
shares the database, for example through a Compose override file. Keep it
unset to leave offers off. Do not set it to an empty string.
