## Worker exits

The paused worker, `sdk-worker-1`, exited and was restarted 7 times in all.
The other worker never exited.

- **Native refusal shape (6 exits).** After a pause, the worker sent requests
  for workflow tasks the server had given to the other worker. Native refused
  the late lease renewal (`task_not_leased`, 5 times) or late completion
  (`conflicting_completion`, once) with only a reason and the task fence.
  Published PHP refuses the same
  requests with the ownership guard's fields: the task status, and whether
  the run is closed. A current worker uses those fields to recognize a lost
  claim. [#548](https://github.com/durable-workflow/server/pull/548) makes
  native return PHP's bodies, with a parity fixture.
- **SDK 2.0.10 poll (1 exit).** A poll got HAProxy's HTML 503 while a killed
  node was still marked up. SDK 2.0.10 treats that body as invalid JSON and
  exits. The SDK has retried polls on that failure since
  [sdk-php#69](https://github.com/durable-workflow/sdk-php/issues/69).

Current SDKs still exit when the same proxy failure hits a request for a
task that is already claimed:
[sdk-php#197](https://github.com/durable-workflow/sdk-php/issues/197).
