# Selected-run SDK signal profile

This pending profile uses the frozen published tuple from namespace signals,
with six PHP/Rust client by PHP/Python/Rust author directions. The ordinary
authors remain unchanged. New senders call the actual published selected-run
methods; Python 2.5.4 is an author only.

The [acceptance document](../../../../docs/rust-server-selected-run-signals.md)
records original budgets, zero-mutation guards, durable rejected-command effects,
canonical embedded differences and qualification gates. The recorder retains
real HTTP phase sidecars and read-only original-run database snapshots. The
reader checks commands, signals, counters, history, neighboring state and task
fences rather than relying on response status alone.

Reference, reader regression, native implementation and all-six exact candidate
and fresh-main qualification are pending. This profile is explicitly selected;
it does not enlarge the default qualified corpus or relax frozen evidence.
